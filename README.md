# The Design Case — Solo Practice

Self-paced single-player version of **The Design Case**, the Prototyping with Numbers module game from [d.MBA](https://d.mba). Live at:

> **https://dmbateam.github.io/design-case-practice/**

Pitch a redesign with numbers. Five execs each want a different financial argument; pick the one you can defend best.

## What this repo is

A static mirror of the solo build. Source of truth for development is the private `dmbateam/design-case` repo (which also hosts the multiplayer/workshop version). This repo only exists so GitHub Pages can serve the site for free.

**Don't edit files here directly.** Changes get overwritten by the next sync.
